# 26.4 — General Mod Support Removal: Dependency Map and Removal Plan (Agent 7)

Branch: `dev/26.4`. Read-only mapping; no code was changed, no build/test run (per `LOCAL_ENVIRONMENT.md`, verification is CI's job).

## 0. Executive conclusion

The fork contains **two independent mod systems** plus a set of **built-in features implemented on top of the native-mod host API**:

| System | What it is | Classification |
|---|---|---|
| **A. WebAssembly sandbox mods** (`mods` Cargo feature, `horizon-mods` `runtime`) | Discovery, install, enable/disable, live switch, mod browser, management UI, config, `--dev-mod` | **General mod support → REMOVE** |
| **B. Native mods / mixins** (`mod_api`, `native_hooks.rs`, generated traits, `cargo-horizon-mod`, SDK, build service, JNI, registry) | External code mods downloaded, installed, compiled into a custom game build and run | **General mod support → REMOVE** (external loading/discovery/build/management paths) |
| **C. Native-mod HOST API inside `game/native_hooks.rs`** | Call sites + host helpers (`native_on`, `native_setting`, `native_mod_key`, `NativeMod` list, tick/HUD/key/frame dispatchers) | **PRESERVE** — voice chat and the built-in Android bundled features run through it (see §3.1, §5) |
| **D. Built-in bundled features** (voice chat, zoom, minimap, recipes, SmartF3) | Shipped in the binary, not downloaded; no mod loader required | **PRESERVE** (Horizon extras / Android features / voice chat) |

**Central constraint (TASK §5C, reinforced by Agent 6):** removing the *external* mod-loading infrastructure must not remove the native-mod *host helpers* that the built-in Simple Voice Chat client uses. Voice chat is NOT a mod loader consumer — it is a standalone client that happens to be wired into the host API. Deleting `native_on`/`native_setting`/`set_setting`/`native_mod_key`/`NativeMod`/tick-HUD-key-frame dispatch would delete voice chat's settings, keybinds, enable switch and per-frame/tick driving. Those helpers stay; they become **internal built-in-feature host infrastructure**, no longer an extension point for third-party mods.
